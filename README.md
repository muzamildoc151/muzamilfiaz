# Dr. Muzamil Fiaz — CV Website

Professional monochrome CV-style static website.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to your repository. Then go to **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`.

For `muzamilfiaz.site`, add the domain under **Settings → Pages → Custom domain**, configure the DNS records recommended by GitHub, wait for verification/certificate issuance, then enable **Enforce HTTPS**.

HTTPS is provided by GitHub Pages, not by the website code.
